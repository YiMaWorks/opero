# Opero 翻译用语表（所有语言照这个来）

Opero 是一个自己部署的「AI 开发团队」：主人在聊天 App 里指挥 AI 员工（Claude Code / Codex）查 bug、改代码、发版、管服务器。界面语气：简短、口语、直接，像聊天 App，不要官腔。

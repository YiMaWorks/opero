Opero：你自己部署的 AI 开发团队，装在一个聊天 App 里

Opero 是开源（Apache-2.0）、装在你自己服务器上的 AI 开发团队。Claude Code / Codex 员工跑在你的服务器上，替你查 bug、改代码、发版本、盯日志、管运维；账号密码加密存在你自己的服务器上，AI 拿不到；你在手机上的聊天 App 里看结论、点卡片做决定。

Opero is an open-source, self-hosted AI dev team you run from a chat app. Claude Code and Codex employees work on your own servers: they catch bugs, fix code, ship releases, watch logs and run ops. Credentials stay encrypted on your server and never reach the AI; you make the calls from your phone.

为什么用 Opero

  • 会话不再乱：每个员工一个会话，有角色、有记忆。
  • key 不交给 AI：员工通过 Opero 连服务器、数据库、云，只看到结果；危险操作要你指纹确认。
  • 一个 App 打通：开发、测试、部署、上线、日志巡检、发现 bug、在线修复、发版，每一步都有员工负责。
  • 你只管业务：员工去查、去做；你看结论、点卡片。

能做什么

  • 日志巡检：员工盯日志，自己发现 bug，写清原因、影响和建议。
  • 修 bug：一句「修复」，员工在分支上改好、检查通过、发布上线，失败自动退回上一版。
  • 运维：服务器负载、数据库查询、DNS、证书、安装包，都在聊天里完成。
  • 多端：手机、电脑浏览器和安卓 App（苹果、Windows 原生 App 在做）。

安装

  1. 准备一台 Linux 服务器（2 核 4G 起，有 systemd）。
  2. 用 root 运行：curl -fsSL https://raw.githubusercontent.com/yimaworks/opero/main/code/server/scripts/install.sh | sudo bash
  3. 打开它给的地址：设账号 → 一键安装 Claude Code → 登录 → 建员工。

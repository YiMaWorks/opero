# code/android：Opero 安卓 App（Kotlin + Jetpack Compose，逐步原生化）

核心页面原生（Compose），还没做原生的页面用 WebView 打开网页（`code/web`）。推送、指纹、JS 桥见 `docs/规范/App外壳.md`，接口见 `docs/api/`。

安卓的交接、版本记录在 `docs/android/`（`交接.md`、`变更记录.md`），开工先读交接最上面几条。直接在 master 上改，只提交 `code/android`、`docs/android`。

> **方向：逐步原生化**（`docs/多端架构.md`）。新页面用 Kotlin + Jetpack Compose 写，先做核心：登录（账号密码 `POST /api/app/login`，开了两步验证再 `/api/app/login/mfa`；配对码登录保留为可选；拿到设备令牌 + 会话令牌，带 `Authorization: Bearer`）、会话列表、聊天（消息、卡片、状态行、停止、插话 / 排队、附件）；其它页面继续用 WebView 打开网页（`/api/app/ticket`），再一页页换。现有的推送、指纹、App 内更新、通知渠道照用。接口照 `docs/api/`；要后台改接口交给后台负责人，不改 `code/server`。

## 文字和翻译

- 代码里直接写中文原文：`t("登录")`、`t("连不上 {0}：{1}", host, err)`（不要用 `${}` 拼进原文，变量用 `{0}`）。
- 字典：编译时 Gradle 任务 `operoI18n` 把 `code/web/src/i18n/locales/<语言>.json` 原样拷成 `assets/i18n/web-<语言>.json`（和网页同一份），App 独有的句子放 `code/android/i18n/<语言>.json`（拷成 `app-<语言>.json`，同一句以它为准）。后台发来的中文提示也按字典换。
- 加了文字跑 `node code/android/scripts/i18n-check.mjs`，缺哪句补进 `code/android/i18n/` 六种语言（zh-TW、en、ja、de、fr、ar），`{0}` 占位一个不能少。
- 语言跟 Opero 设置（`settings.lang`，各端一样），没设就跟手机系统。通知渠道名这些系统级文字还在 `res/values-*/strings.xml`。

## 编译 / 发版

- 开发机上不编 Android。在 Opero 里：项目 opero 的编译组件「安卓」（模板 android、`subdir=code/android`、`versionFile=code/android/app/build.gradle.kts`、只走云效流水线 5421218）。改完提交推送后 `build_try component=安卓` → `build_status component=安卓` 看日志，编出没签名的 release 包（`*-unsigned.apk`）。
- 发版前改 `app/build.gradle.kts` 的 `versionName` 和 `versionCode`。
- 签名：发布目标配签名证书（Opero 的签名证书凭证），部署前签名；证书不进仓库。发布由人来发。

## 怎么测（编出来以后）

1. **登录**：装上打开 → 「连接你的 Opero」：地址填自己装好的 Opero（`https://你的域名` 或 `http://IP:7300`），填官网 / 随便的网站会提示「这个地址不是 Opero 后台」→ 账号（邮箱）+ 密码；开了两步验证再输动态码；或者「用配对码登录」（网页「我 → 账号安全 → 接手机」拿码）。网页上断开这台手机 → App 回到登录页并说明。
2. **会话列表**：和网页的会话一样多、顺序一样；员工在干活时绿点 + 那句状态实时变；长按 → 置顶 / 免打扰，网页上跟着变；右上 ＋ 选员工开会话；搜索。
3. **聊天**：发一句 → 员工开始干活（三个点 + 在做什么，10 秒不变开始走秒）；干活时再发 = 插话，点「排队」= 排队（下面出排队列表，能改、能删）；没字时按 ■ 停止；往上翻到顶加载更早的；翻上去时来新消息右下角出「↓ N 条新消息」。
4. **附件**：＋ → 图片（多选）/ 拍照 / 文件，输入框上面出一排，传好后跟着下一句一起发；× 撤回。图片在聊天里按比例显示，点开看大图（左右滑翻、存到相册 → 系统相册 Pictures/Opero 里有、分享 → 系统分享面板、转给员工 → 对方会话里是那张图）；文件点一下存到「下载」（Download/Opero），长按有打开 / 分享。安卓 9 及以下存的时候让你选位置。
5. **卡片**：让员工发一张要确认的（比如让它跑一个危险命令）→ 点「确认执行」弹系统指纹；ask 卡片单选后「就这样」；一轮做完员工最后一句下面有小结（文件数点开看明细、撤销 / 发布）。
6. **嵌网页**：员工 / 项目 / 应用 / 我 四个页签是网页的页面，没有网页自己的底部页签；页面里点到聊天 → 开原生聊天；点到别的页面 → 再压一层（最外层有「关闭」）；返回键先关网页里的弹窗 / 子页。
7. **其它**：语言跟网页「我 → 设置」里选的；深色主题时整个 App 变深；点通知直达那个会话、正开着那个会话时不弹；「我 → 设置 → 这台手机」：指纹解锁、接收提醒、严重告警一直响。

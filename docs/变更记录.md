# opero 变更记录（最新在最上面）

## server 0.6.1 + web 0.19.1（2026-11-23）
- GitHub 仓库地址改成 https://github.com/yimaworks/opero（官网、安装命令、Agent 接入命令、安装说明、App 连接页）。已经装好的机器 `opero update` 一次就改连新地址。

## server 0.6.0 + web 0.19.0（2026-11-23）
- Agent 指纹：每台 Agent 第一次启动生成自己的 ed25519 密钥（私钥不出那台），每个请求都签名，Opero 按指纹（`SHA256:…`）认机器——换了上报地址也认得，不用重新接入。没带令牌也能接：那台按指纹来连，网页「等你接受」里核对指纹（那台上 `opero fingerprint`）后点接受。
- Opero 指纹：Opero 自己一对密钥，派给 Agent 的活都签名；Agent 第一次连上记住这个指纹，之后只执行它签过名的活（别人冒充地址也指挥不了机器）。迁移：数据目录带过去指纹不变，网页「指纹和迁移 → 换地址」一键让所有 Agent 改连新地址，或在那台上 `sudo opero agent-url <新地址>`；换成另一套 Opero 时带上它的指纹才认。
- 安装命令的令牌可以不带（`--agent <地址>`）。

## server 0.5.0 + web 0.18.0（2026-11-23）
- AI 网络出口：Claude Code、Codex 可以各选一个出口——直连、经 Opero 这台、或经任意一台装了 Agent 的服务器（比如国内服务器干活、经海外那台连 Anthropic / OpenAI）。照 KidLock「走 agent 出海」，复用 Agent 已有的连接，出口那台不用开端口；做成隧道（TLS 端到端），流式回复也能用。出口只连 AI 相关域名、拒绝内网地址。一键安装、登录、员工干活都走选的出口；「AI 执行器」里有「测一下通不通」。

## server 0.4.0 + web 0.17.0（2026-11-23）
- 聊天排队：员工在干活时，回车 = 插话（Claude Code），点「排队」= 这一轮做完再发；插不进去的（Codex）自动排队。排队的每条都带着自己的图片 / 文件，存数据库（重启不丢、所有设备都看得到），输入框上面显示排队列表（缩略图、能删）；这一轮正常结束按顺序自动发，你点了停止就等你点「开始处理排队」。
- 发图片 / 文件改成先传、显示在输入框上面（能撤回），跟着下一句话一起发（插话、排队都带上）；去掉了原来「只发图 8 秒后自动派活」。

## web 0.16.0 + server 0.3.1（2026-11-23）
- 多语言：简体中文、繁體中文、English、日本語、Deutsch、Français、العربية。默认跟随系统；选了就记住，装好的一套同步到后台和所有设备（手机 App 是同一个网页，跟着换）。官网、试用版、装好的一套都能换（官网右上角、登录页底部、「我 → 设置 → 外观 → 语言」）。阿拉伯语从右往左排。

- 安卓外壳的连接页跟手机系统语言（7 种）。
- 触发器的定时规则改成点选（每隔几分钟 / 几小时、每天、工作日、每周几 + 时间），不用手写中文格式。

## server 0.3.0 + web 0.15.0（2026-11-23）
- **Agent 管理**：别的服务器一条命令装 Opero Agent（`install.sh --agent <地址> <令牌>`，令牌在「应用 → 服务器和 Agent → 接入」生成，30 分钟、一次性），主动连回 Opero，不用开端口；重装 / 换令牌重跑认得是同一台（机器编号）；可以和 KidLock 的 Agent 装在同一台。服务器页分「员工能在上面干活（本机 + Agent）」和「只用 SSH」，显示 Agent 版本、心跳、装了哪些执行器；能移除 Agent、重新接入。
- 员工可以选「跑在哪台服务器」；AI 执行器按服务器装和登录（账号共用）；工作空间可以拉到装了 Agent 的服务器上；聊天里发给远程员工的文件会送到那台。远程员工的 MCP 经 Opero 地址连回来。
- 登录 Claude：授权码交上去后显示登录界面最后几行、2 分钟没结果自动停下说明原因；失败提示认得更多说法；令牌被界面折行时也能拼回来。

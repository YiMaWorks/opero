# opero 变更记录（最新在最上面）

## web 0.50.0（2026-11-27）
- 员工按项目分组：员工页、电脑侧栏的员工栏都按项目分开（顺序同项目列表，没有项目的放最后，组里置顶的在前）。员工页每组标题旁有「项目」（打开那个项目）和「+ 加员工」（直接给这个项目加一个）。

## web 0.49.2（2026-11-27）
- 「项目」页更紧凑：项目卡按内容高度（以前固定 250 高，手机上下面一大片空白），仓库地址只显示最后两段（AI/opero-yima）。手机上发布概况收成一行小格（能左右滑），说明条不显示。

## web 0.49.1（2026-11-27）
- 修：手机浏览器里「验证本人」点「用指纹 / 面容确认」每次都报一串英文（The operation either timed out or was not allowed）。原因是通行密钥加在别的设备（比如电脑）上，这台手机的浏览器里没有，但界面照样把指纹当主按钮。现在：这台浏览器用指纹失败过、又没在这台加过，就默认用密码（「用指纹」还在下面）；失败时框里用中文说清楚原因、自动切到密码，验证完问要不要在这台也加上指纹。挑战码打开弹窗就先要好，点按钮直接叫指纹（以前先去后台要，有的浏览器会当成不是你点的直接拒绝）。登录页、账号安全里加通行密钥的报错也换成了中文。

## web 0.49.0（2026-11-27）
- 「项目」和「发布」合在一起：菜单里只剩「项目」。「项目」页上面是发布概况（近 30 天发了几次、成功率、失败、回滚、平均耗时、正在发），每个项目一张卡（各环境线上是哪个版本、最近一次发布），下面是全部发布记录；点卡片进项目。项目页最上面就是发布：各环境的线上版本、「发布」「回滚」「编辑」、这个项目的发布记录，下面才是编译、安装包、员工、分支。
- 正在发布时，侧栏里那个项目后面显示「发布中」。以前的「发布」链接（聊天卡片、员工菜单、App 里）都会打开对应的项目页 / 项目总览。

## server 0.32.0 + web 0.48.1（2026-11-27）
- 发布卡片显示版本号（比如「线上已经是 0.30.0」「回滚到 0.29.3」），不再是 c0b6caa 这种提交号。编译设置里没配版本号文件也认得出：先看产物文件名（opero-0.30.0.tgz、app-1.2.3.apk），再看仓库里那个提交的 package.json / VERSION / gradle / pom / Cargo / pyproject；都没有才用提交号。以前的发布记录也按产物文件名显示版本号。提交号还在，小字放在旁边。

## server 0.31.1（2026-11-27）
- 修：聊天里每轮的花费算错了，偏大很多（「本次」「会话」、用量统计、预算都受影响）。Claude Code 报的花费是累计值，而且续上会话时会把之前的花费带回来，以前 Opero 把每次的累计又加了一遍。现在按「最新累计 − 这一轮开始时带着的」算。之前记下的数字没改，还是偏大的。

## server 0.31.0 + web 0.48.0（2026-11-27）
- **网络出口**：Opero 连不上某些地址（比如在国内连 Gmail、Telegram、OpenAI），可以让它经一台能连上的服务器出去。在「应用 → 服务器和 Agent → 网络出口」按域名加一条（子域名一起管），收发邮件、提醒渠道、AI Key、生图、DNS、流水线、代码平台的接口都按它走；那台只要装了 Agent，不用开端口，内容全程加密。
- 不知道是哪个地址也没关系：连不上的会自动列在「最近连不上的」，点「换个出口」地址就带好了；常见的（Gmail、Telegram、Slack、OpenAI…）点一下就填；选出口是一张张卡片，离线、Agent 太旧的直接写着为什么不能选；先测再存，直连和经出口通不通都摆出来。规则能就地改出口、备注、域名。
- 员工也能帮你设：新工具 `egress_manage`（看最近连不上的、测、设、删）。默认不许经出口连内网地址，要连就在规则上勾「允许内网」（要验证本人）。
- 当出口的 Agent 要 0.31.0 以上（服务器详情里点「升级 Agent」）。

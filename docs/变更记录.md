# opero 变更记录（最新在最上面）

## web 0.13.1（2026-11-23）
- 安装改成全走 GitHub：官网不再放安装脚本和程序包；推荐把一句话发给服务器上的 AI（照 `INSTALL.md` 装），也可以手动运行 GitHub 上的安装脚本。官网接上 GitHub 链接。

## server 0.1.0 + web 0.13.0（2026-11-23）
- 第一个能装的版本：`curl -fsSL https://opero.yimaworks.com/install.sh | sudo bash`（程序包和安装脚本跟着 web 一起发到官网 `/download/`、`/install.sh`）。
- 后台：主人登录；和 Claude Code / Codex 员工真聊天（流式、插话、停止、新话题、图片 / 文件）；Opero MCP 代理（SSH 服务器、MySQL / PostgreSQL、Git 同步、审核 / 确认 / 选方案卡片、知识库、转派、发文件）；加密保险箱 + AI 单独系统用户；服务器 CPU / 内存；定时 / Webhook 触发器；操作记录；用量；安卓外壳配对和推送。
- 网页：装好的一套走真接口；还没做的功能显示「还在做」。官网安装一节改成真的。

## web 0.12.1（2026-11-23）
- 官网：`/` 是落地页（深色会动的首屏、演示和讲解视频、界面图、对比表、安装步骤，中英文按域名切换），`/demo` 是界面原型（假数据，不连服务器）。
- 含 0.8～0.12.0：14 套风格 + 自己配色、顶部快捷换风格、电脑端统一三栏、图片编辑器（所有上传先裁剪）、「我」顶部个性化、聊天像 IM（头像、尖角气泡、长按菜单）、顶栏显示服务器 CPU / 内存、发版后自动换新版。

## web 0.1.0（2026-11-22，发布 #365，生产 https://opero.yimakeji.cn）

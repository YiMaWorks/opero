# 安卓变更记录（最新在最上面）

> 安卓 App（`code/android`）的版本记录。0.4.0 及以前的也在 `docs/变更记录.md` 里。版本号在 `code/android/app/build.gradle.kts`（`versionName` / `versionCode`）。

## android 0.5.0（2026-11-28，还没编通）
- App 的界面改成直接用网页的手机版：和网页一模一样，网页更新了 App 里马上就有。登录还是原生的（账号密码 / 配对码 / 两步验证），登录后不用再登录网页。
- 网页里点下载：图片存到相册、文件存到「下载」，不再跳去浏览器（浏览器里没登录，下不了）。
- 系统分享（发微信等）：外壳准备好了，网页接上以后能用。
- 返回键一层层退（聊天 → 会话列表 → 桌面）；点通知直达那个会话，正看着的会话不弹通知。
- 之前写的原生会话列表 / 聊天（0.4.x）先收起来，不在 App 里了。

## android 0.4.2（2026-11-27，还没编通）
- 常用语点一下就直接发给员工，不用先进输入框；输入框里正在写的不受影响。员工在干活插不进去时排队，会提示「已排队」。
- 常用语能排序：点「编辑」后长按一个拖到想要的位置，松手就存（电脑、手机上都是这个顺序）；删除改成每个后面的 ×。

## android 0.4.1（2026-11-27，还没编通）
- 聊天里的图片：点开看大图，左右滑翻这个会话里的图片；能存到相册、用系统分享（发微信等）、转给员工。
- 文件：点一下存到手机的「下载」；长按还能打开、分享。
- 转给员工改成后台转（要 server 0.29.0）：图片 / 文件把文件本身给对方，不再只转一个文件名。

## android 0.4.0（2026-11-27，还没编通）
- 会话列表和聊天做成原生的：会话列表（置顶、红点、在干活、长按置顶 / 免打扰、找员工聊、搜索）；聊天里消息、Markdown、图片、文件、卡片（确认 / 选择 / 问题 / 通用）、一轮小结、在干活气泡（走秒、停止）、插话 / 排队、附件（图片、拍照、文件）、语音、常用语、底部菜单、长按复制 / 引用 / 转发 / 删除、加载更早、新消息提示、上下文快满提示；开新会话接着做以后自动跟到新会话。
- 发布卡片原生画（server 0.25.10 起的新格式）：步骤时间线、进度、用时、失败原因和日志、回滚 / 重发。
- 危险的卡片按钮弹手机系统指纹验证本人。
- 底部五个页签：会话是原生的；员工、项目、应用、我 先用网页的页面（只显示那一页），页面里点到聊天会打开原生聊天。
- 数据实时更新（和网页同一套推送），断线自动重连；点通知直达那个会话。

## android 0.3.0（2026-11-27，没单独发）
- 工程加上 Jetpack Compose；登录页改成原生的（地址 → 账号密码 → 两步验证；也能用配对码）。
- 网页上断开这台手机、改了密码 → 回登录页并说明原因；连不上时有出错页（重试 / 退出登录）。
- 界面文字用网页同一份字典（七种语言），跟 Opero 设置的语言走，阿拉伯语从右往左。
- 指纹验证本人 5 分钟内不再问（和后台一致，原来是 30 分钟）。

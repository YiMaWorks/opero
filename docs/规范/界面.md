# 界面规范

所有页面照这一份做：长得一样、用起来一样。改组件、加页面前先看这里；样式在 `code/web/src/styles.css`，组件在 `code/web/src/components/ui.tsx`。

## 1. 原则（先看这个）

1. **能点不填，能自动不问**。默认值替用户想好（端口、名字、分支、服务器、环境标签），用户只在想改的时候才动。必须手填的只剩密码、令牌、Key 这类只有用户知道的东西。
2. **一屏一件事**。主操作只有一个（`btn primary`），其它是 `default` / `ghost`。一般不用动的设置收进「高级设置（一般不用动）」。
3. **不要「给自己看的备注」输入框**。名字不填自动起，说明文字由系统生成。
4. **每个要去别处拿东西的地方都要有指引**：直达链接按钮 + 一步步的步骤 + 要给的权限 + 能复制的命令（见 `credmeta.ts`）。
5. **确认只留给危险操作**：删除用确认框（`confirm`）；发布生产、在生产服务器 / 生产库上改东西、看密码明文、账号安全设置才「验证本人」。其它直接做，记进操作记录。
6. **常用操作放外面**：置顶、发消息、切分支这类每天都用的，放在列表行上 / 页面顶部，不藏进菜单。
7. **在哪看到就在哪改**（2026-11-27 主人定的）：页面上显示出来、能改的东西（名字、职责、项目名、执行器和模型、环境…）就在原地改——文字用 `InlineText`（`components/ui.tsx`：点一下变输入框，回车 / 点别处保存，Esc 不改，后面一支淡笔提示能改），成组的设置弹出就地的面板（比如员工行上点「执行器 · 模型」弹 `WorkSheet`、发布环境卡片上点「编辑」）。不要让人点进第二、第三层页面才能改。
8. **图片一律先裁剪**（2026-11-27 主人定的，默认，不用再说）：任何上传 / 选图片的地方都先过图片编辑器（`components/ImageEditor.tsx` 的 `pickImages` / `editImage`：裁剪、缩放、旋转），头像固定正方形、圆形遮罩。不要直接把原图存进去。
9. **头像哪里显示哪里能换**：员工头像用 `EditableAvatar`（`components/AvatarPicker.tsx`，右下角小相机，点了弹 `AvatarPicker`：36 张默认头像分女生 / 男生、上传图片、字或表情、底色）。
10. **红点必须消得掉**（2026-11-27 主人定的）：任何红点、数字角标、「要你决定」这类提醒，都要在出现的地方说清楚「是什么事、在哪处理、怎么消」，并且一定有一个不用真去做也能消掉的办法（「以后再说」「忽略」「不行」）。做不到就不要加红点。**消掉的地方必须一眼能找到、不能藏起来**：不能只靠鼠标悬停的提示（手机上没有悬停）、不能放在二级菜单或要滚动才看到的地方；在干活等别的状态也不能把它盖住；红点 / 数字本身要能点，点了直接到要处理的地方（底部「会话」的数字点了直接打开等你的那个会话）。红点要按真实状态算（还有没有没处理的事），不能「记一次就不管」——处理了、失效了、重启了都要跟着消。聊天里的实现：等你处理的卡片带 `needYou`，后台 `chat.syncWaiting` 重算会话的「要你决定」，网页 `Chat.tsx` 顶上提示条（是什么 · 去看 · 以后再说）+ 卡片下一句说明。
11. **技术活交给员工，界面不摆出来**（2026-11-28 主人定的，项目页那次）：编译、发布环境怎么配、文档（docs/）、同步方式这些，用户不用接触、也不该被约束——跟员工说一句就行，任何员工都能做。界面上**只给结果和动作**（线上是哪个版本、发布 / 回滚、装哪个包），不给配置项。已经是标准的不做开关（比如项目**一定自动同步**，多端一起用才不出问题），没意义的设置直接去掉（比如项目预算）。
12. **系统知道的不让用户填**：比如发布环境属于哪个端（Web / 安卓 / iPhone…）看安装包格子、编译组件就知道，自动认，界面上直接显示。
13. **按端分开**：不同的端（Web、安卓、iPhone、Mac、Windows…）各自发、各自管，现实里很多不用一起发。页面顶上按端分选项卡（只有一个端就不出选项卡），每个端里放它自己的环境、发布记录、安装包（安装包属于那个端，不单独放一块）。
14. **列表默认只给最近几条**（发布记录 3 条，带日期、哪个端、版本号），要看更多点「全部」。
15. **只读的信息就显示成信息**：比如项目代码来自哪个仓库、用哪个账号拉，接入时定了就不变，显示成一行字，不要给下拉框让人以为能随便换。
16. **删除这类不可撤销的：页面最底下单独一个好看的危险按钮，一定二次确认**（说清楚删了会怎样、要输入名字确认），不要混在别的按钮里。
17. **手机（H5）上要宽松**：一行里别塞两三个按钮，次要信息挪到第二行；字头像里的字要居中。
18. **一块只放一件事，不混功能**（2026-11-28 主人定的，订阅用量框那次）：标题说是什么就只放什么（「订阅用量」只放订阅账号，API Key 不进来）；系统支持的每一种都列出来，没接入的就写「未接入」+ 去接入的入口，而不是拿别的东西填进来或者干脆不显示。

## 2. 布局

- 电脑：左边窄栏（页签）· 目录（340）· 内容。内容区最宽 880，居中。手机：一页一页进，底部页签。
- 页签（电脑左边窄栏、手机底部一样）：**会话 · 员工 · 项目 · 应用 · 我**。
  - **我**：只放跟主人这个人有关的——资料、我的习惯、外观和通知（风格、语言、推送什么、这台手机）、账号安全（密码、通行密钥、两步验证、设备）、退出登录。
  - **应用**：员工干活用的（服务器、凭证、数据、发布、问题清单、域名、收件箱、消息渠道、触发器、知识库、操作记录），下面一组「这套 Opero 的配置」（AI 执行器、用量和成本、系统设置、关于；试用版还有定制和二开）。**新加的配置类页面一律放「应用」，不要放进「我」。**
- 聊天页：顶部「员工资料」按钮和「···」（聊天信息）、底部菜单打开的页面，**一律从右边滑出**（电脑：聊天右侧面板；手机：整页从右边滑进来），不用居中弹窗。只有很短的选择（work 设置、附件、语言、风格）用底部弹出的 `Sheet`。
- 聊天顶部标签不重复下面已有的东西（项目名在底部菜单里，顶部只留分支）。
- 拖进图片 / 文件：整个会话区都能接。
- 页面头（`PageHeader`）：标题 + 一行说明 + 右边最多两个按钮。
- 内容由一组组 `Section` 组成：标题在卡片外（左边粗体，右边放这一组的操作，如「+ 加一个员工」「授权凭证」），内容在卡片里。

## 3. 组件怎么选

| 要做的 | 用 |
|---|---|
| 一行信息 / 进下一页 | `Row`（标题、灰字说明、右边值或按钮、可点就带箭头） |
| 2～5 个互斥选项 | `Segmented` |
| 6～15 个选项、多选、标签 | `chips`（`chip`，选中 `on`）；末尾可接一个 `chip-input`「别的」 |
| 选项很多（凭证、仓库、文件） | 右边侧滑 `Drawer`（带搜索、分类筛选、勾选、底部「确定」）；仓库 / 文件用列表 + 搜索 |
| 小表单 | `Sheet`（电脑居中，手机底部） |
| 服务器上的路径 | `PathInput`（输入框 + 「选…」浏览） |
| 服务器上的服务 | `ServicePick` |
| 开关 | `lrow` + `Toggle`，右边说明一句后果 |
| 提示 | `banner b-info / b-ok / b-warn`；字段下面一句 `field-hint`；页面底部 `hint` |
| 空状态 | `Empty`：说清楚下一步点哪里 |
| 状态 | `Tag`：ok 绿 / warn 黄 / danger 红 / mute 灰；环境标签用 `envTone` |
| 获取步骤 | `cred-guide`：标题「怎么拿」+ 直达按钮 + 有序步骤 + 权限 + 可复制代码块 |

## 4. 颜色、字号、间距

- 颜色全用变量（`--primary` `--text` `--sub` `--faint` `--line` `--panel` `--ok` `--warn` `--danger`），深色 / 浅色主题自动换；不写死颜色（分类图标的点缀色除外）。
- 字号：页标题 17，正文 14，说明 12～12.5，标签 12。
- 圆角：按钮 8，输入框 10（`--radius`），卡片 12～14，标签全圆。
- 间距：组和组之间 24，卡片内边距 14～16，标签之间 8。

## 5. 文字

- 口语、短句、先说结论；按钮用动词（「接入」「授权凭证」「切换分支」），不用「确定」「提交」这类空词（对话框底部除外）。
- 说明最多两行；更长的放「怎么拿」步骤里。
- 不写内部实现词（API、字段名），除非用户真的要填它（比如 `{{secret:名字}}`）。
- 所有界面文字是简体中文源文，改了以后跑 `node scripts/i18n-extract.mjs` 补 6 种语言（见 `code/web/src/i18n/GLOSSARY.md`）。

## 6. 新页面自查

- [ ] 有没有能自动补 / 能点选却让人填的字段？
- [ ] 页面上显示的、能改的东西，是不是在原地就能改（不用再进一层页面）？
- [ ] 加了红点 / 角标的：有没有写清楚是什么事、怎么消？有没有「以后再说 / 忽略」这种不处理也能消的办法？处理了、失效了它会不会自己消？
- [ ] 主操作是不是只有一个？一般不用动的收进高级了吗？
- [ ] 要去别的平台拿东西的地方有没有直达链接和步骤？
- [ ] 列表多了（> 15 项）会不会挤？要不要改成侧滑 + 搜索？
- [ ] 确认 / 验证本人是不是只在危险操作上？
- [ ] 手机上能不能用（宽度 360 看一眼）？

# Opero 品牌（v0.1，2026-11-21）

- `opero-logo-候选.png`：三款候选对比（A 对话 O、B 轨道 O、C 气泡终端）。**2026-11-21 选定 A**。
- 下面的单独文件都是 A 款：
  - `opero-icon.svg` / `opero-icon-1024.png`：App 图标（紫色渐变底 + 白色标志 + 薄荷绿点）
  - `opero-mark.svg` / `opero-mark-white.svg`：只有标志（浅底用紫、深底用白）
  - `opero-logo.svg` / `opero-logo-dark.svg`：横版字标——**标志当「O」+ pero**（浅底紫标 + 墨色字 / 深底亮紫标 `#8E7EFF` + 白字），预览 `opero-logo-横版预览.png`。尺寸关系：圈的外径 = 大写字母高度（0.75 × 字号），线宽 ≈ 粗体笔画
- 颜色：紫 `#7C6CFF → #4F3FE0`（渐变），薄荷绿 `#2EE6B0`（和界面「在干活」状态点一致），深色 `#171A26`。
- 含义：O 的左下角长出气泡尾巴 = 聊天就是入口；中间的绿点 = AI 员工在干活。
- 生成脚本：`code/design-mockups/logo.py`。字标暂用思源黑体 Bold，正式版可换定制字形。

## 启动页（动画，v2：标志变成字标里的 O）

- **规矩：标志不能和字一样颜色**（2026-11-21 定）。标志永远是品牌紫（渐变）+ 薄荷绿点；字用白（深色底）或墨色（浅色底）。所以启动页底色改成深色（不再用紫色底）。
- 深色为默认；网页版跟随系统：浅色模式时自动换白底（`opero-splash-深浅对比.png`）。

- 动画（约 2.6 秒后进入等待）：0.1–0.9 秒画出 O 和气泡尾巴 → 0.85 秒绿点弹出 → 1.25–1.85 秒标志缩小、移到「Opero」的 O 位置 → 1.7 秒起 p e r o 依次出现 → 2.15 秒标语淡入 → 2.6 秒起绿点呼吸（「AI 在干活」），直到加载完成。
- `opero-splash.gif`：预览（3 倍 1080×1920，和手机屏幕一样不再放大；256 色分两份：96 色给背景渐变、160 色给标志 / 字边缘过渡，不抖动——边缘不出锯齿、背景不起色带）；`opero-splash.png`：最终画面（3 倍）。有的 App 里动态 WebP 不会动、HTML 打不开，所以预览只出 GIF / PNG。
- `opero-splash.html`：网页版（CSS 动画），**由 `code/design-mockups/splash.py` 生成，别手改**。网页 / 桌面 / App WebView 通用；加载完给 `#splash` 加 `done` 淡出；「减少动态效果」时直接显示最终画面。字标是整个单词一起排（换字体不会错位），字母只做淡入。
- 标语暂定「和 AI 团队聊天，搞定开发」（英文待定）。
- 安卓：系统启动画面（Android 12 SplashScreen）只放静态图标 + 紫色底，紧接着显示这个动画页，聊天 WebView 好了再淡出。
